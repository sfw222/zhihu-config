# zhihu-config

油猴脚本合集，用于知乎深色/浅色主题切换 + 页面美化。

## 脚本

### 1. 知乎深色/浅色主题切换

- 通过油猴菜单一键切换深色/浅色主题（默认深色）
- 修复知乎原生深色模式下少量组件遗漏
- 移除 AI 总结卡片

**安装：** [点击安装 zhihu-config.js](https://raw.githubusercontent.com/sfw222/zhihu-config/main/zhihu-config.js)

### 2. 知乎美化

- 隐藏各页面侧边栏（拉宽内容），一键开关
- 链接转直链
- 回答/文章发布时间置顶
- 问题创建/编辑时间显示
- GIF 自动播放
- 引用角标高亮

**安装：** [点击安装 知乎美化.js](https://raw.githubusercontent.com/sfw222/zhihu-config/main/知乎美化.js)

## 使用

- **主题切换：** 点击油猴图标 → 脚本菜单 → 选择「深色模式」或「浅色模式」
- **美化脚本：** 点击油猴图标 → 脚本菜单 → 「知乎美化设置」切换侧边栏显示/隐藏
