# zhihu-config

油猴脚本，用于知乎深色/浅色主题切换与深色模式样式补丁。

## 功能

- 通过油猴菜单一键切换深色/浅色主题（默认深色）
- 修复知乎原生深色模式下少量组件遗漏
- 移除 AI 总结卡片

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
2. 点击安装脚本：[zhihu-config.user.js](https://raw.githubusercontent.com/sfw222/zhihu-config/main/zhihu-config.js)

## 使用

点击油猴图标 → 脚本菜单 → 选择「深色模式」或「浅色模式」。
